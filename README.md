# FLIGHT-HR-SOLUTIONS

Website project for **Flight Hour Solution GmbH** (Zug, Switzerland), an independent jet-engine management consultancy. Despite the repository name, this is "Flight *Hour* Solution", not a human-resources company.

- `docs/research/` — the research dossier prepared before the rebuild (start with `docs/research/README.md`).
- `.claude/skills/` — agent skills installed for the research and build phases (`skills-lock.json` pins versions).
